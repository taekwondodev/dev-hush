# Hush conversation-only behavior

Expected line: previously Hush hid intermediate reports and streaming prose, revealing only the last assistant response at settlement. Hush must now show all assistant prose, including streaming messages, intermediate reports, and prose attached to tool calls, without showing thinking, tool arguments, scripts, or raw tool output.

With Hush active, hide agent tool calls and results (including customized tools) and thinking. Keep all assistant text visible while the agent runs and after settlement, including reports followed by automatic continuation and final questions referring to earlier reports. Keep the working indicator while the agent runs. Preserve completed replies when a new run starts. Keep user inputs and blocking approval dialogs visible. Show only quota/usage-limit and provider-connectivity diagnostics; suppress other automatic assistant diagnostics (including abort and truncation). Hide ordinary tool failures, including bash exit codes and edit/write errors. Show a compact red notice identifying failed agent children from dev/work results or outcome messages, read from their `details` (the result's attempt, inspection or snapshot records, and the outcome entries) and never from model-visible content, but not failed local processes, cancelled children, or raw logs. Child notices add one blank line before the notice, matching provider-error spacing; horizontal padding is unchanged. Disabling Hush restores details. Execution, model context, session history, and exports remain complete and unchanged.

Regression: a report followed by continuation and a final response must retain both report and final response. Prose attached to tool calls remains visible, while thinking and tool calls remain hidden. Toggling Hush or exporting restores the original content. Quota and provider-connectivity failures must retain their diagnostics; other automatic diagnostics stay hidden. Reloading the extension disables the previous final-only presentation hook.

Error-filter expected line: previously every failed tool showed a notice and every non-routine dev/work outcome could expose raw details. With Hush active only quota/provider-connectivity diagnostics and failed agent-child summaries are shown. Ordinary tools and local process failures remain completely hidden. Disabling Hush or exporting restores all original diagnostics, commands, and output. Agent-authored prose remains visible and is not rewritten.
